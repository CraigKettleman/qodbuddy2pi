# 2.0.0 是破坏性变更，安装器清理旧命令

这次改动删除了 `workbuddy2pi-global` 命令、把 `workbuddy2pi/` 与 `qoder2pi/` 两个目录整个移除、
重排了入口文件，并改变了 npm 包的 `files` 清单。已有用户升级后，`~/.local/bin` 里会留下指向
已不存在文件的旧命令。

因此决定：版本跳到 2.0.0，安装器负责清理它自己上一版装下的旧命令与旧目录。

## Consequences

- 清理是安装器职责的自然延伸：它已经是唯一会改动本机的组件，知道哪些文件是自己管的。
- 不残留旧命令很重要：`workbuddy2pi-global` 升级后会指向一个不存在的文件，报出的错误
  （`command not found` 或 node 的模块找不到）对用户毫无提示作用。
- 与 `wb-account` 的旧处理一致：现有安装器已经会把旧命令备份成 `.bak-<时间戳>` 再替换，
  这次沿用同样的做法，不直接删除用户文件。
